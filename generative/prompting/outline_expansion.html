🗺️ Outline Expansion Pattern

Ask a Large Language Model (LLM) for a 2,000-word guide in one go, and you get thin, generic sections, or the reply is cut off before it ends. The outline expansion pattern builds the document in pieces instead: first an outline, then you choose which part to expand, as deep as you need, and finally you assemble the finished sections.

Why it works

  • Each reply stays short. The model writes one section at a time, so nothing gets cut off at the length limit.
  • You decide where the depth goes. You pick which part to expand, so the important sections get detail and the rest stay brief.
  • The structure comes first. Agreeing on the outline before writing keeps the final document organized: 🪄 Idea → 🗂️ Outline → 🌿 Branches → 🧬 Leaves → 🪢 Assemble.

Example interaction

A short loop that seeds the expander, gets an outline, then expands one branch at a time.

1 Seed the expander

UserAct as an outline expander. Generate a bullet point outline based on the input that I give you and then ask me which bullet point to expand. Ask me what to outline.
ModelPlease provide the topic, target audience, desired length, and any must-include constraints.

2 Describe the topic, get an outline

UserTopic: developer onboarding guide for our internal CLI.
Audience: new backend engineers.
Length: about 2,000 words.
Constraints: emphasize security and reproducibility.

4 Go one level deeper

5 Write the leaves, then assemble 🔁

Once the outline is deep enough, ask for each leaf in full. Every reply is a short, finished section you can paste into the guide:

UserWrite 6.2.1 in full, in about 100 words.
Model · write 6.2.16.2.1 Secure Retrieval Process
Never copy an API token from a chat message, a wiki page or a teammate's screen. Request your own token through the internal access portal, which ties it to your account and sets an expiry date. The CLI reads the token from your system's secret manager, not from a file in your project, so it never ends up in Git. If the CLI asks you to paste a token into a config file, stop and report it: that is a bug, not a setup step.

Each leaf arrives as a short, finished section, so the full 2,000-word guide is assembled from pieces that never hit the length limit.
