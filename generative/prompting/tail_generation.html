🧵 Tail Generation Pattern

A Large Language Model (LLM) loses track of the conversation's goal as the conversation grows. The instructions you gave at the start get buried under newer messages, so later replies drift: rules get dropped and the model stops asking for what comes next. The tail generation pattern fixes this by ending every reply with a short “tail” that restates the goal, the rules, and the next step, so they are always among the most recent messages.

Why it works

  • It reinforces continuity. Restating the objectives and rules at the end of every reply keeps them in front of the model, so it sustains constraints and task focus across long multi-turn conversations.
  • It names the next step. The tail spells out the next required user input, so the model keeps asking for the right thing.
  • It reminds the model of itself. Self-reminders in the tail carry the model's own working notes from one turn to the next.

Example interaction

The user sets up a repeating workflow: for every task, the model suggests a few approaches and writes one prompt per approach.

1 The user's instruction

The second paragraph, “End every reply with a tail…”, is what installs the tail.

UserWhenever I give you a task, restate the task, list three different approaches to it, and write one prompt for each approach. Then ask me for the next task.

End every reply with a tail that restates the goal of this conversation, the rules above, and what you need from me next.

Ask me for the first task.

2 The model's first reply

ModelReady. What task would you like prompts for?--- Goal: write prompts for your tasks, one per approach. Rules: restate the task, list 3 approaches, write 1 prompt per approach, ask for the next task. Next: tell me your first task. ---

The reply is short, but the tail already carries the whole workflow forward.

3 Fifteen turns later

By now the original instruction is far back in the conversation. Here is the same request sent with and without the tail:

UserFind the main risks in a company's quarterly financial report.
Before · no tail · ModelHere's a prompt you can use: “Read this quarterly report and summarize the main risks.”

The model writes a single prompt, skips the approaches, and doesn't ask for the next task.

After · with a tail · ModelTask: find the main risks in a quarterly financial report.

1. Fixed checklist. “List every risk in this report under four headings: revenue, profit margins, debt, and cash flow.”
2. Quarter-on-quarter comparison. “Compare this report with last quarter's and list each figure that got worse, with both numbers.”
3. Management's own words. “Quote every sentence in the management commentary that mentions a decline, an uncertainty, or a risk, and explain each in one line.”

What's the next task?--- Goal: write prompts for your tasks, one per approach. Rules: restate the task, list 3 approaches, write 1 prompt per approach, ask for the next task. Next: tell me your next task. ---

The model follows every rule and ends with the tail again, ready for the next turn.
