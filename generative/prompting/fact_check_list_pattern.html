🕵️ Fact Check List Pattern

The fact check list pattern makes a Large Language Model (LLM) list the discrete facts its answer relies on. Once those atomic claims are explicit, a human or a second checker can verify them and catch hallucinations early.

Why it's needed 🧭

  • Models make confident mistakes. LLMs are probabilistic text generators, so they inevitably make mistakes, confidently produce wrong statements, and sometimes emit prose that looks authoritative while lacking grounded factual support.
  • They complete patterns, not questions. They are not literal question-answer tools; they are pattern completers that approximate likely continuations.
  • Explicit claims can be checked. A structured prompt that forces the model to surface the atomic claims it relies on lets a human or an automated checker verify them, catch hallucinations early, and decide whether the response is trustworthy, instead of silently accepting polished but unfounded output.

Installing the pattern ⚙️

The goal is to force the model to externalize the factual claims it asserts, then verify them in a fresh context. Start by telling the model to append its facts to every answer.

1 Minimal prompt

prompt
Any time you produce a text give me the facts that you have produced.

2 Expanded, more prescriptive prompt 📐

This version says where the facts go and which facts matter: the fundamental ones that would undermine the output if any were wrong. It is shown as originally provided, including its typos.

prompt
Whenever you output text, generate a set of facts that are contained in the output.
The set of facts should be inserted at the end of the output.
The set of facts whould be fundamental facts that could underminde teh veracity of the output if any of them is incorrect.

Verify in a fresh context 🔄

3 Check the facts independently

Open a fresh conversation with no prior context, paste the answer and its fact list, and ask:

prompt
Please check if the facts in the text match the facts in the bullet point list.

4 Label, correct, repeat 🧪

Checker · model or humanLabels each fact Supported or Not Supported and suggests corrections.

🔐 Loop until all facts are validated. This reduces the likelihood that polished but incorrect claims pass through unnoticed.
