📐 Output Template Pattern

Ask a Large Language Model (LLM) for the same kind of output twice, and it may format it differently each time. The output template pattern gives the model an exact layout with placeholders: the model fills in the placeholders and keeps the rest of your formatting exactly as you wrote it.

Why it works

  • The layout is fixed. You define exactly how the response looks, so the model can't choose its own structure.
  • Placeholders mark what changes. The model fills only the variable parts and leaves everything else exactly as written.
  • Every run matches. The output stays consistent across many generations, which makes it easy to process further.

The template prompt

A practical example that turns facts into question–answer flashcards:

UserI am going to give you a template for an output. Capitalized words are my placeholders. Fill in my placeholders with your output. Preserve the overall formatting of my template.

My template is

Question word in Italic followed by : and placeholder QUESTION, write the letters capitalized.

Answer word in Italic followed by : and placeholder ANSWER

I will give you the data to format in the next prompt. Create twenty questions using my template. Wait for me to give you the data.
ModelUnderstood. Send me the data, and I'll turn it into questions and answers using your template.

What this prompt establishes

  • Placeholder convention: capitalized words.
  • Formatting requirements: italic labels, capitalization rules.
  • Expected structure: question–answer pairs.
  • Generation quantity: twenty questions.
  • Multi-turn interaction: wait for the data before generating.

Before and after

The same facts, sent to a model without the template and to the model above:

UserPhotosynthesis is the process by which plants convert light energy into chemical energy. The telephone was invented by Alexander Graham Bell in 1876.
Before · no template · ModelThose are two interesting facts! Photosynthesis is how plants turn sunlight into energy, and Alexander Graham Bell patented the telephone in 1876. Would you like to know more about either one?

Without a template, the model just chats about the facts instead of formatting them.

After · with template · ModelQuestion: WHAT IS PHOTOSYNTHESIS?

Answer: The process by which plants convert light energy into chemical energy

Question: WHO INVENTED THE TELEPHONE?

Answer: Alexander Graham Bell invented the telephone in 1876

Every card follows the template: italic labels, a capitalized question, and the answer below it.

Use cases

The output template pattern works best wherever the format has to be the same every time:

  • Structured data generation 📊 — Generate CSV, JSON, or XML-like formats.
  • Educational content 📚 — Create flashcards, quizzes, or study materials.
  • Documentation 📝 — Produce API docs, changelogs, or release notes.
  • Reports 📈 — Generate standardized reports with fixed sections.
  • Form filling 📋 — Complete templates with variable information.

Related patterns

The output template pattern combines well with other prompting strategies:

  • Few-Shot — Provide filled template examples to guide the model.
  • Persona — Apply templates to persona-specific outputs.
  • Chain-of-Thought — Template the reasoning steps before the final answer.
