🔍 Question Refinement

Question refinement uses pre-prompting: a brief, reusable directive that runs before any conversation and asks a Large Language Model (LLM) to clarify or improve each user input. It turns vague queries into precise questions that yield higher-quality answers.

Why it matters

  • Higher answer quality. Specific, well-scoped questions reduce ambiguity and error.
  • Faster resolution. Fewer back-and-forth turns to reach the real need.
  • Better user trust. The model demonstrates listening and intent alignment.
  • Reusability. The same pre-prompt works across many domains with minimal tuning.

The prompt 🔧

Paste this once at the start of a conversation, or put it in the system prompt:

prompt
Whenever i ask a question, suggest a better question and ask me if i would like to use it instead.
UserMake my site faster
Model · with pre-promptA better question might be: “Which pages have slow Largest Contentful Paint (LCP), and can we prioritize image optimization for those pages first?” Would you like to use it instead?

FAQ

Is this the same as chain-of-thought (CoT)?

No. Chain-of-thought reveals intermediate reasoning steps. Question refinement focuses on clarifying what to answer before answering. They can be combined but serve different goals.

When should I skip refinement?

When the user is clearly specifying a deterministic action, such as “convert this JSON to CSV”.

⚠️ Over-refinement becomes friction.
