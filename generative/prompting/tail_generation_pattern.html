🧵 Tail Generation Pattern

The Tail Generation Pattern extends each Large Language Model (LLM) response with a concise, structured “tail” that reiterates active objectives, governing rules, next required user input, and self-reminders.

Why it works

  • It reinforces continuity. Restating the objectives and rules at the end of every reply keeps them in front of the model, so it sustains constraints and task focus across long multi-turn conversations.
  • It names the next step. The tail spells out the next required user input, so the model keeps asking for the right thing.
  • It reminds the model of itself. Self-reminders in the tail carry the model's own working notes from one turn to the next.

When to use

Use this pattern in extended sessions where the model begins drifting from instructions, forgets constraints, changes style midstream, or stops asking for the correct next input.

Before · no tailDeep into a long session, replies drift from the instructions, drop constraints, change style, or stop asking for the correct next input.
After · with a tailEvery reply ends with a tail that restates the task, the active rules, and the next expected input, so the workflow stays on track.

1 The user's instruction

prompt
"" Whenever i ask you to write a prompt for me to accomplish a task,
list what the task is,
list alternaltive approaches for completing the tesk,
and then write a prompt for yourself for each approach.
When you are done, ask me for the next prompt to create alternatives for.

Ask me for what I want you to write a prompt for.""
