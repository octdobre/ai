🏁 ReAct Prompting

A Large Language Model (LLM) only knows what was in its training data, so when you ask about something recent or very specific, it guesses. ReAct (Reason + Act) makes the model alternate between short reasoning steps and actions with tools, such as searching the web or opening a page, and answer only from what it found.

Why it works

  • Answers come from sources. The model looks facts up instead of recalling them, so fresh or very specific information comes out right.
  • Each step is visible. You can read what the model was looking for, what it did, and what it found.
  • Several sources can be combined. The loop keeps going until the evidence is enough, then compiles one answer with its sources.

The prompt

Ask the question, then tell the model to follow the ReAct loop until it has enough evidence:

UserQuestion: When did the running race of the 2021 Tiroler Firmenlauf start? 🏃🏁

Follow ReAct: iterate Thought → Action → Observation until sufficient evidence, then provide a concise Final answer followed by a Sources list.

Example output

The model works through repeated Thought → Action → Observation cycles, then answers with its sources. Each observation is the result a tool returns, which the app passes back to the model.

1 Search for the race

Model · Thought 1I should search for a report on the 2021 Tiroler Firmenlauf in Innsbruck that gives the start time.
Model · Action 1web_search(query="Tiroler Firmenlauf 2021 Start Uhrzeit")
User · Observation 1 · tool resultResults include a race report on hdsports.org with the 2021 results and photos.

2 Open the race report

Model · Thought 2Open the race report to find the start time for the runners.
Model · Action 2web_get(url="https://www.hdsports.org/firmenlauf/ergebnisse-tiroler-firmenlauf-2021-fotos")
User · Observation 2 · tool resultThe report says the race took place on 18 September 2021, that the runners started at 17:00 (“Gestartet wurde das Rennen für die Läufer um 17:00 Uhr”), and that the walkers started ten minutes later.

3 Check the details

Model · Thought 3The report states the start time directly and also gives the walkers' start, so the evidence is specific enough to answer.

4 Final answer with sources

Model · Final answerThe running race of the 2021 Tiroler Firmenlauf started at 17:00 on 18 September 2021 in Innsbruck. The walkers started ten minutes later, at 17:10. 🏁

Sources:
  • hdsports.org race report: hdsports.org/firmenlauf/ergebnisse-tiroler-firmenlauf-2021-fotos

The answer uses only what the model found, and names the page it came from.
