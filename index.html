🚀 All prompting patterns

Root prompting →Establish invariant principles to guide downstream prompts. Persona pattern →Structure a model's role, voice, and constraints. Audience pattern →Tailor outputs to a specific reader with appropriate depth, tone, and structure. Grammar and prompting →How nouns, verbs, and modifiers shape LLM outputs. Game play pattern →Let the model act as a Game Master to run rules-based sessions. Menu actions pattern →Trigger keywords that expand into longer instructions. Fact Check List pattern →Enumerate atomic claims for verification to reduce hallucinations. Tail generation pattern →Append a structured tail to preserve objectives across turns. Pre-prompting →Set context and constraints before the ask. Question refinement →Improve questions via pre‑prompting. Flipped interaction →Let the model ask one-at-a-time questions, then deliver when ready. Alternative approaches pattern →List and compare multiple ways to accomplish a task. Ask for input pattern →Force a handshake so the model requests inputs before solving. Cognitive verifier →Decompose with sub‑questions, then synthesize. Recursive prompting →Iteratively refine outputs with self-critique and re-asking. Chain-of-thought prompting →Elicit intermediate reasoning steps for complex tasks. ReAct prompting →Reason-and-act workflow to retrieve evidence and compile answers. Recipe prompting pattern →Fill in missing steps while respecting known constraints. Outline expansion pattern →Outline, then expand branches to build large outputs within token limits. Compressing input information →Strategies to shrink inputs without losing signal. Word completion →Encourage targeted completions with minimal context. Few-shot prompting →Teach a format and decision pattern with short exemplars. Output template pattern →Define exact output format with placeholders. Meta language creation →Teach the model custom notation or shorthand. Semantic filter pattern →Remove low-signal, sensitive, or redundant spans while preserving meaning.
