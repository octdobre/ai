The software behind LLMs

A large language model (LLM) is software with two parts: a program called the engine, and a file of trained data called the model. The engine loads the model, takes your text and returns an answer.

The engine and the model

Many programs can act as the engine. A popular one is llama.cpp, written in C++: it loads a model and does the calculations. Nothing in its code knows French, Python or history. All of that information is contained in the model it loads.

The model is a database of numbers called weights. “Llama 2 70B”, for example, has 70 billion of them at 2 bytes each, which makes a 140 GB file. Unlike an ordinary database, it holds no sentences or facts you could look up, only numbers that represent patterns learned from training text.

The engine does the work. The model holds the knowledge.

From training to a running instance

The weights are set during a training process, which ends with a final model file. That file is fed into llama.cpp, which starts an instance of the model. You can then send it text and get text back, although the model itself never sees text.

Tokens

Instead, it works with tokens: words or pieces of words, each with an ID number. “Unbelievable” might become “Un”, “believ” and “able”. The engine encodes your input into an array of these numbers and decodes the numbers that come back. “Llama 2” knows 32,000 different tokens.

A statistical guess

Using its trained weights, the model predicts which token is most likely to come next, one token at a time. Every reply is therefore a statistical guess.

So when you ask a question, the answer depends on two factors:

  • How the model was trained: what data it saw and how well the training went.
  • The quality of the model: its parameter size, meaning how many weights it has, and its quantization, meaning how much those weights were rounded to fit a smaller file.

Depending on these, the answer can be accurate or extremely imprecise. A wrong answer presented confidently as fact is what's now called a hallucination.
